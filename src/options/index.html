フォロー設定

Chrome で note.com にログイン済みであれば、その Cookie セッションを使います。パスワードは保存しません。

自動フォロー返し

自分のフォロワーを取り込み、まだフォローしていない人を古い順にフォローします。開始日時を入れて保存すると、その日時から自動で動きます。フォローに成功した相手には、同じ流れでお礼メッセージも送ります。

テスト実行は、誰が対象になるか確認するだけです。実際にはフォローしません。本番はポップアップの「フォロワーを取り込んで開始」か、開始日時どおりの自動実行です。

保存しました 


      
手動の urlname リスト

      

        自動取り込み以外に、フォローしたい人を 1 行に 1 人ずつ書けます。
      

      

        例: fuji1080 / https://note.com/fuji1080 /
        @fuji1080。先頭が # の行はコメントです。
      

      
      
      
0 人


      
フォロー返しのお礼メッセージ

      

        自動フォローでも、リストからでも、フォローに成功した相手へ定型のお礼を送ります。note.com に送信 API が無いため、メッセージ画面を開いて送信ボタンを押します。
      

      
      
      
      

        {nickname} は表示名、{urlname} は ID に置き換わります。相手がメッセージ受信をオフにしている場合は送れません。上の「保存」でリストとお礼設定も一緒に保存されます。
      


      
フォロー解除（片思い・退会）

      

        こちらがフォローしていて、相手がフォローしていない人は全員解除します。退会した人も対象です。実行とテストはポップアップの「フォロー解除」から行います。フォロー返し・お礼・開始日時の設定は変わりません。
