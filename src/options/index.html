フォロー設定

Chrome で note.com にログイン済みであれば、その Cookie セッションを使います。パスワードは保存しません。

自動フォロー返し

自分のフォロワーを取り込み、まだフォローしていない人を古い順にフォローします。開始日時を入れて保存すると、その日時から自動で動きます。お礼メッセージは下の追加機能です。

テスト実行は、誰が対象になるか確認するだけです。実際にはフォローしません。本番はポップアップの「フォロワーを取り込んで開始」か、開始日時どおりの自動実行です。

保存しました 


      
手動の urlname リスト

      

        自動取り込み以外に、フォローしたい人を 1 行に 1 人ずつ書けます。
      

      

        例: fuji1080 / https://note.com/fuji1080 /
        @fuji1080。先頭が # の行はコメントです。

追加機能: フォロー返しのお礼メッセージ

      

        フォローに成功した相手をキューに入れ、ポップアップから 1 人ずつ note.com のメッセージ画面を開きます。送信 API は非公開のため、本文の下書きまで行い、送信は自分で確定します。
      

      
      
      
      

        {nickname} は表示名、{urlname} は ID に置き換わります。相手がメッセージ受信をオフにしている場合は送れません。上の「保存」でリストとお礼設定も一緒に保存されます。
