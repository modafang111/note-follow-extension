# note.com フォロー拡張

note.com に **手動ログイン済み** の Chrome セッション（Cookie）を使い、**フォローしてくれた人へフォロー返し**する Manifest V3 拡張です。

パスワードやセッション文字列は保存しません。フォロー処理は公式ではない Web API を呼び出します。

お礼メッセージは、**フォロー返しが成功した相手へ同じ流れで送ります**。テスト実行では送りません。

## できること

### 自動フォロー返し（本体）

- 自分のフォロワーを取り込み、まだフォローしていない人を古い順にフォロー返し
- 設定画面で **開始日時** を入力して、その日時から自動実行
- 繰り返し: 1回だけ / 30分ごと / 1時間ごと / 毎日
- **テスト実行**: 対象になる人を確認するだけ（実際にはフォローしない）
- ポップアップの **フォロワーを取り込んで開始** で本番のフォロー返しを今すぐ実行
- 次回の自動実行時刻をポップアップに表示
- 既にフォロー済み・自分自身・一度処理した人はスキップ
- フォロー成功後、定型の **お礼メッセージを送信**（メッセージ画面を開いて送信ボタンを押す）

### フォロー解除（片思い・退会）

- 自分がフォローしている人のうち、**相手がフォローしていない人**と**退会した人**のフォローを解除
- ポップアップの **片思い・退会を解除** で実行
- 設定画面で **開始日時** を入れて、**毎週1回** 自動解除
- **解除のテスト実行**: 対象になる人を確認するだけ（実際には解除しない）
- フォロー返し・お礼・開始日時とは別に動く。同時には動かさない

### 手動リスト

- urlname を 1 行 1 人で指定
- ポップアップの **リストから開始 / 停止**

### 共通

- `GET /api/v2/creators/{urlname}` で数値 ID / key を取得
- `POST /api/v3/users/{key}/following` でフォロー
- `GET /api/v2/creators/{urlname}/followings` でフォロー中を取得し、`DELETE /api/v3/users/{key}/following` で解除
- 1 件ごとに **3〜5 秒のランダム待機**
- 進捗・ログをポップアップに表示
- 完了・停止・失敗時に Chrome の通知（日付と時刻つき）と、アイコン上の「実行 / 完了 / 停止」表示

## 必要環境

- Node.js 20 以降
- Google Chrome（または Chromium 系）

## ビルド

Windows では、フォルダ内の **`update.bat`** をダブルクリックすると、`git pull` → `npm install` → `npm run build` までまとめて実行します。終わったら Chrome の `chrome://extensions` で拡張を **再読み込み** してください。

コマンドで自分でやる場合:

```bash
npm install
npm run build
```

成果物は `dist/` に出力されます。

## Chrome への読み込み（ローカル）

1. Chrome で [chrome://extensions](chrome://extensions) を開く
2. 右上の **デベロッパーモード** をオンにする
3. **パッケージ化されていない拡張機能を読み込む** をクリック
4. このリポジトリの **`dist`** フォルダを選択する
5. ツールバーに「note.com フォロー」が追加される

コードを直したあとは `npm run build` を再実行し、拡張の **再読み込み** を押してください。

開発中にホットリロードしたい場合は `npm run dev` を使い、同じ手順で Vite が出力するディレクトリ（通常は `dist`）を読み込みます。

## 使い方

1. Chrome で [note.com](https://note.com/) を開き、**いつもどおり手動ログイン**する
2. 拡張アイコンをクリックし、**自動フォローと対象リストを設定** を開く
3. **開始日時** と繰り返しを入れて、**自動フォロー返しを使う** にチェックして保存
4. 先に対象を確認したいときは **テスト実行**（フォローはしません）
5. 今すぐ本番で返すときは、ポップアップの **フォロワーを取り込んで開始**
6. フォローに成功した相手へ、お礼メッセージの送信も続きます
7. 途中で止めたいときは **停止**
8. 片思いや退会した人のフォローを外すときは、ポップアップの **片思い・退会を解除**。毎週自動にするときは設定の開始日時を入れて保存。先に確認するときは **解除のテスト実行**

手動リストから始めたいときだけ **リストから開始** を使います。urlname の書き方:

```
example_user
https://note.com/another_user
@someone
```

### お礼メッセージ

フォローに成功すると、相手のメッセージ画面を開いて定型文を入れ、送信ボタンを押します。送れなかった人はポップアップの「お礼を送り直す」に残ります。

お礼文の定型は設定の「フォロー返しのお礼メッセージ」で変えられます。`{nickname}` と `{urlname}` が使えます。相手がメッセージ受信をオフにしている場合は送れません。テスト実行ではフォローもお礼も行いません。

ポップアップを閉じても、実行中のジョブはバックグラウンドで続きます。再度開くと進捗が復元されます。

## 注意

- note.com の非公式 API を使っています。仕様変更で動かなくなることがあります
- 短時間に大量フォローすると制限やアカウント制限の対象になる可能性があります。対象リストは必要最小限にしてください
- この拡張はログイン Cookie を読み取って API を呼び出すだけで、パスワードは扱いません
- お礼メッセージは note.com の送信 API が無いため、メッセージ画面を開いて送信ボタンを押す方式です。画面の変更で失敗することがあります
- テスト実行はフォローしません。本番のフォローは「フォロワーを取り込んで開始」か、開始日時の自動実行です
- フォロー解除のテスト実行は解除しません。本番の解除は「片思い・退会を解除」です。相互フォローの相手は外しません
